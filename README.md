# AI 提示詞評估系統 使用說明

## 📋 功能簡介

這是一個自動化的 AI 提示詞評估系統，用於測試和評估 Claude 在生成 AWS 相關程式碼（Python、JSON、Regex）時的表現。

## 🚀 快速開始

### 1. 安裝依賴套件

```bash
pip install anthropic python-dotenv
```

### 2. 設定環境變數

建立 `.env` 檔案並加入你的 Anthropic API 金鑰：

```
ANTHROPIC_API_KEY=你的_API_金鑰
```

### 3. 執行程式

```bash
python 提示詞評估系統.py
```

## 📊 程式執行流程

```
步驟 1：生成測試資料集
   ↓
步驟 2：執行評估（讓 Claude 解決任務）
   ↓
步驟 3：雙重評分（語法 + AI 評分）
   ↓
步驟 4：輸出詳細結果並儲存檔案
```

## 📁 輸出檔案

執行完成後會產生兩個 JSON 檔案：

- **資料集.json**：生成的測試任務
- **評估結果.json**：完整的評估結果（包含分數、優缺點、評分理由）

## 🎯 評分機制

每個測試案例都會獲得兩個分數：

1. **語法分數**（0 或 10 分）
   - 檢查生成的程式碼是否符合語法規則
   - JSON → 使用 `json.loads()` 驗證
   - Python → 使用 `ast.parse()` 驗證
   - Regex → 使用 `re.compile()` 驗證

2. **AI 評分**（1-10 分）
   - 由 Claude 評估程式碼品質
   - 提供優點、缺點、評分理由

**最終分數 = (語法分數 + AI 評分) / 2**


## 🔧 自訂設定

你可以修改以下參數：

```python

model = "claude-haiku-4-5"  # 更換使用的模型

# 在 generate_dataset() 函數中
請生成 3 個物件。  # 修改生成的測試案例數量
```
